# FIFO Project Instructions

This subproject inherits the workspace root `AGENTS.md` in full.

## Scope

- This repository contains the FIFO common component design and verification collateral.
- Keep changes focused on reusable FIFO logic, tests, build scripts, and documentation.
- Do not weaken workspace-level rules around Git safety, validation, project memory, or tooling.

## Tooling

- Use `uv` for Python environments, dependencies, and scripts.
- Use Verilator for Verilog/SystemVerilog simulation when applicable.
- Prefer narrow mechanical verification before broader runs.
